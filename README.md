# 로블록스 끝말잇기 검색기

- `index.html`과 `words.json`을 같은 폴더에 둔 뒤 웹 호스팅에 올리면 됩니다.
- GitHub Pages / Cloudflare Pages / Netlify 같은 정적 웹 호스팅에 업로드할 수 있습니다.
- PC에서 테스트할 때는 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`으로 접속하면 됩니다.

현재 버전의 한방 분류는 “마지막 글자로 시작하는 다음 단어가 파일에 존재하지 않는가” 기준의 즉시 한방(1수 종료)입니다.
2수 이상 한방, 양보단어, 순환단어는 별도의 정확한 게임 규칙/분류 알고리즘이 확인되면 추가 구현할 수 있습니다.
